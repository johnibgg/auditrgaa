RGAA 4.1 : les 38 critères qu'un outil peut vérifier, et les 68 qui exigent un humain

Le référentiel général d'amélioration de l'accessibilité compte 106 critères. Les outils automatiques en contrôlent une partie seulement : 38, soit 36 %. Cette page dit lesquels, thème par thème, et pourquoi les autres ne peuvent pas l'être.

Cette page est générée depuis notre moteur d'analyse, pas rédigée à la main. Si nous ajoutons une règle, elle apparaît ici ; si nous en retirons une, elle disparaît. Une page de référence qui se désynchronise de l'outil qu'elle décrit devient un mensonge poli.

Deux thèmes sortent du lot. Les couleurs sont intégralement automatisables : un rapport de contraste est un calcul. Le multimédia l'est à peine : juger si des sous-titres sont fidèles à la bande-son suppose de l'écouter.

Le détail, thème par thème

Pour chaque thème : les critères que nous contrôlons, le défaut que cela détecte, et pourquoi le reste échappe à la machine.

1. Images

2 / 9 automatisables
  • Critère 1.1 Image sans alternative textuelle ; Bouton image sans alternative ; Zone cliquable d'image réactive sans alternative ; Élément role=img sans alternative ; SVG informatif sans alternative ; Élément object sans alternative
  • Critère 1.2 Image décorative mal neutralisée

Pourquoi le reste échappe à la machine. Un logiciel voit qu'une image a une alternative ; il ne peut pas juger si « photo1.jpg » décrit correctement le graphique de chiffre d'affaires qu'elle contient.

2. Cadres

2 / 2 automatisables
  • Critère 2.1 Cadre sans titre ; Cadre non analysable
  • Critère 2.2 Titres de cadres non uniques

Pourquoi le reste échappe à la machine. La pertinence du titre d'un cadre suppose de comprendre ce qu'il y a dedans.

3. Couleurs

3 / 3 automatisables
  • Critère 3.1 Lien identifiable uniquement par la couleur
  • Critère 3.2 Contraste de couleurs insuffisant
  • Critère 3.3 Contraste de couleurs insuffisant ; Contraste insuffisant (niveau AAA)

Pourquoi le reste échappe à la machine. Le rapport de contraste se calcule. En revanche, savoir si une information est donnée uniquement par la couleur demande de lire la page.

4. Multimédia

3 / 13 automatisables
  • Critère 4.1 Vidéo sans sous-titres ; Audio sans transcription
  • Critère 4.3 Vidéo sans sous-titres
  • Critère 4.13 Son déclenché automatiquement

Pourquoi le reste échappe à la machine. Le sous-titrage, l'audiodescription et la transcription se vérifient en regardant et en écoutant. Aucune machine ne juge si des sous-titres sont fidèles.

5. Tableaux

3 / 8 automatisables
  • Critère 5.4 Titre de tableau simulé ; Titre de tableau redondant
  • Critère 5.6 En-tête de tableau vide
  • Critère 5.7 En-tête de tableau sans cellules associées ; Attribut headers incorrect ; Attribut scope invalide ; Cellule de tableau complexe sans en-tête

Pourquoi le reste échappe à la machine. Distinguer un tableau de données d'un tableau de mise en forme demande de comprendre le contenu.

6. Liens

1 / 2 automatisables
  • Critère 6.1 Lien sans intitulé explicite ; Liens identiques vers des cibles différentes ; Bouton sans intitulé

Pourquoi le reste échappe à la machine. On détecte un lien vide. On ne détecte pas qu'« En savoir plus » est ambigu dans son contexte.

7. Scripts

2 / 5 automatisables
  • Critère 7.1 Attribut ARIA non autorisé ; Rôle ARIA non autorisé ; Attribut ARIA obligatoire manquant ; Structure ARIA incomplète ; Élément ARIA hors de son conteneur ; Rôle ARIA invalide ; Attribut ARIA invalide ; Valeur d'attribut ARIA invalide ; aria-hidden sur le corps de page ; Contrôles interactifs imbriqués ; Contrôle ARIA sans nom ; Jauge sans nom ; Barre de progression sans nom ; Infobulle sans nom ; Boîte de dialogue sans nom
  • Critère 7.3 Élément masqué mais focusable ; Zone défilante inaccessible au clavier

Pourquoi le reste échappe à la machine. Le comportement réel d'un composant interactif — ce qui se passe quand on l'active au clavier — se teste en l'utilisant.

8. Éléments obligatoires

5 / 10 automatisables
  • Critère 8.2 Identifiant dupliqué ; Identifiant ARIA dupliqué ; Identifiant dupliqué sur élément actif
  • Critère 8.3 Langue de la page non indiquée
  • Critère 8.4 Code de langue invalide ; Déclarations de langue contradictoires
  • Critère 8.5 Page sans titre
  • Critère 8.8 Changement de langue invalide

Pourquoi le reste échappe à la machine. La langue déclarée se vérifie ; la pertinence du titre de page par rapport à son contenu, non.

9. Structuration de l'information

3 / 4 automatisables
  • Critère 9.1 Hiérarchie de titres incohérente ; Titre vide ; Absence de titre de niveau 1 ; Faux titre (paragraphe en gras)
  • Critère 9.2 Absence de région principale ; Régions non distinguables ; Plusieurs en-têtes de page ; Plusieurs pieds de page ; Plusieurs régions principales ; En-tête imbriqué ; Complément imbriqué ; Pied de page imbriqué ; Région principale imbriquée ; Contenu hors de toute région
  • Critère 9.3 Liste mal structurée ; Élément de liste orphelin ; Liste de définitions mal structurée ; Élément de définition orphelin

Pourquoi le reste échappe à la machine. La hiérarchie des titres se contrôle. Savoir si elle reflète la structure logique du document, non.

10. Présentation de l'information

3 / 14 automatisables
  • Critère 10.11 Zoom désactivé ; Zoom limité
  • Critère 10.12 Espacement du texte non ajustable
  • Critère 10.13 Ordre de focus incohérent

Pourquoi le reste échappe à la machine. L'essentiel de ce thème concerne l'apparence à différentes tailles et le confort de lecture : cela se constate à l'œil.

11. Formulaires

5 / 13 automatisables
  • Critère 11.1 Champ de formulaire sans étiquette ; Étiquette portée par le seul attribut title ; Champ avec plusieurs étiquettes ; Liste déroulante sans étiquette ; Champ ARIA sans nom ; Case ou interrupteur sans nom ; Bouton de formulaire sans intitulé ; Bouton sans intitulé
  • Critère 11.5 Champs de même nature non regroupés ; Groupe de champs non identifié
  • Critère 11.6 Champs de même nature non regroupés
  • Critère 11.10 Champ obligatoire mal signalé
  • Critère 11.13 Autocomplétion invalide

Pourquoi le reste échappe à la machine. L'existence d'une étiquette se vérifie. Sa pertinence, le contrôle de saisie, la clarté des messages d'erreur, non.

12. Navigation

3 / 11 automatisables
  • Critère 12.7 Absence de lien d'évitement ; Lien d'évitement inopérant
  • Critère 12.8 Élément masqué mais focusable ; Zone défilante inaccessible au clavier ; Ordre de focus incohérent ; tabindex positif
  • Critère 12.10 Raccourcis clavier en conflit

Pourquoi le reste échappe à la machine. L'ordre de tabulation cohérent, la présence d'un plan du site utilisable : cela se parcourt.

13. Consultation

3 / 12 automatisables
  • Critère 13.1 Rechargement ou redirection automatique ; Redirection automatique
  • Critère 13.8 Son déclenché automatiquement ; Contenu clignotant ; Texte défilant
  • Critère 13.11 Cible tactile trop petite

Pourquoi le reste échappe à la machine. Les délais, les changements de contexte, la lisibilité des documents en téléchargement demandent une observation réelle.

Ce que cela change en pratique

Un contrôle automatique n'est pas un audit : c'est un premier tri. Il attrape en quelques minutes les défauts les plus répandus — contrastes, étiquettes de formulaire, alternatives manquantes, hiérarchie de titres — qui représentent l'essentiel des non-conformités réellement rencontrées. Il ne dit rien de la pertinence, du parcours clavier complet, ni de la qualité du sous-titrage.

C'est pour cela qu'un outil qui annonce « votre site est conforme » ment nécessairement. Le nôtre annonce « 38 critères testés, voici le résultat, et voici les 68 qu'il reste à vérifier ». C'est moins vendeur, et c'est le seul énoncé défendable devant un auditeur.
