Testez une page en un clic

Un outil qui analyse l'accessibilité RGAA 4.1 de la page que vous regardez et affiche les défauts, traduits en critères RGAA, directement dans la page. Idéal pour un premier coup d'œil avant un audit complet.

Installez le bouton

Faites glisser ce bouton dans votre barre de favoris (sur ordinateur) :

⚡ Test RGAA

Un clic sur le bouton ici ne fait rien : c'est normal, il faut le glisser dans les favoris, puis le lancer depuis n'importe quelle page.

Comment ça marche

  1. Glissez le bouton ⚡ Test RGAA dans votre barre de favoris.
  2. Ouvrez n'importe quelle page à tester — y compris une page en préprod ou derrière un login.
  3. Cliquez sur le favori : le rapport RGAA s'affiche sur le côté, défaut par défaut.

Son avantage sur les concurrents

Les scanners « collez votre URL » ne voient que les pages publiques. Ce test tourne sur la page affichée dans votre navigateur : il atteint vos environnements de préproduction et vos espaces connectés, là où eux sont aveugles.

En toute honnêteté : l'analyse automatique couvre environ 24 des 106 critères du RGAA 4.1. C'est un excellent point de départ, mais pas une déclaration de conformité : la majorité des critères exigent un contrôle humain. C'est justement ce que nous détestons chez les vendeurs d'« overlays » qui promettent 100 %.

Le test ne transmet aucune donnée : tout se passe dans votre navigateur.
